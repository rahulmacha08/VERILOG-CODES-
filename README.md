# Overview

This repository contains a growing collection of **Verilog HDL source codes and testbenches** developed while learning and practicing digital design and RTL development.

The repository focuses on building a strong foundation in:

- Digital logic design
- Combinational circuits
- Sequential circuits
- RTL modeling
- Verilog HDL
- Testbench development
- Simulation and debugging
- Hardware design concepts

The goal is to move from individual digital logic concepts toward more structured and reusable **RTL design and verification practices**.
